> **TL;DR**
>
> 1. **回测出错的代价不是崩溃，是一张更好看的图** —— 我的引擎 bug 把年化 6.78% / 回撤 −13% 改成 7.85% / −8.97%，我完全没察觉。
> 2. **四个引擎缺陷，四个能反转结论** —— 休市日没对齐、货币 ETF 收益蒸发、权重过度归一化、现金按值传递，每一个都足以让结论反号。
> 3. **我给引擎加了一道门** —— 策略函数现在只能看到"截至当天"的数据，读 `mat[c][i+1]` 直接抛 `LookAheadError`。偷看未来从静默的作弊变成响亮的错误。
> 4. **跑出数字 ≠ 数字有效** —— 样本内最优参数到了样本外可能不如另一组。实测三组动量参数：样本内最"好"的那组，样本外夏普 0.341；另一组 0.518。

## 一个我至今不确定是不是运气好的错误

去年年底我把自己的资产配置脚本重写成一个小工具，想让别人也能跑跑看。

重写完那天我挺满意：数据是真实抓的，指标是全套的，面板也画出来了。我拿它跑了自己的配置，把年化收益发到了群里。

然后我开始写测试。

测试写了不到一小时，就抓出四个 bug。每一个都严重到**能让结论完全反过来**：

| 缺陷 | 它制造出来的结果 |
|---|---|
| 跨市场休市日没对齐 | 休市日持仓被记为 0 → **−90% 回撤、1618% 波动** |
| 货币 ETF 收益蒸发 | 净值恒定 100、收益以份额派发 → "全现金"年化显示 **0%**（真实 1.67%） |
| 权重过度归一化 | 未上市资产的权重被挤到可交易资产上 → 制造出虚假的 **−30% 单年跌幅** |
| 现金按值传递 | 函数内 `cash -= cost` 不回写调用方 → 现金策略年化 **23.65%**（真实 1.8%） |

第四个是我自己在重构时引入的。写测试的过程本身就是一次自我审查——每写一个断言，都是在问"这个数字凭什么可信"。

我报出去的那组数字，最终是年化 **7.85%**、最大回撤 **−8.97%**。而我最初报的是 **6.78%** / **−13%**。

回撤差 **4.03 个百分点**。

> 💡 **Key Insight**
>
> 回测出错的代价不是崩溃，是一张更好看的图。程序照常运行，指标照常输出，CI 照常变绿。没有任何一个环节会告诉你"这个数字是假的"。

## 还有一个不是 bug 的 bug

上面四个都是代码错误。第五个不是——它是**口径**错了，代码完全正确。

我最早从 2001 年开始回测，用的是后来才上市的 ETF。这等于让未来的资产提前入场参与配置。

影响是**低估回撤**。一个 2019 年才上市的标的，在 2001 年就"持有"了 25% 权重，那么 2008 年那轮下跌它根本不在场——跌得自然没那么狠。

代码一行没错，结论彻底错了。

修法不是改代码，是改口径。我现在强制把历史切成两个窗口，而且**永远不混着说**：

- **窗口 A｜投资现实口径（2019-01-18 起）**——起点是所有可投标的都真实上市的最早交易日。这是现实中能执行的口径，是对外结论的主口径。
- **窗口 B｜指数代理长口径（2008-07-01 起）**——用指数代理上市前历史，覆盖 2008 危机。只用来回答"极端行情扛不扛得住"，不代表你买得到。

诚实一点说，窗口 A 才是能拿去决策的那个。窗口 B 是个压力测试。

## 我给引擎加了一道门

上面这些 bug 里有一个共同点：**它们都不会报错**。

所以我在引擎里加了一道护栏。策略函数不再拿到完整的价格矩阵，而是拿到一个**截至当天**的视图：

```python
from vlab import engine, guard

def cheat(date, mat, dates, i):
    # 偷看明天
    return {"sh510300": 1.0} if mat["sh510300"][i + 1] is not None else {}

engine.backtest(cheat, mat, dates)
# → vlab.guard.LookAheadError:
#   策略试图读取未来数据：索引 1 超出当前可见范围 [0, 0]
```

负索引 `mat[c][-1]` 也拦得住——它按真实长度解析，指向的正是未来。

实测：

```text
✅ LookAheadError: 策略试图读取未来数据：索引 21 超出当前可见范围 [0, 20]
```

> 💡 **Key Insight**
>
> 一个专门消灭"回测欺骗"的工具，如果自己留了偷看未来的后门，那它对使用者的承诺就是空的。把作弊变成异常，比写一句"请不要使用未来数据"的注释有用一百倍。

## 但守住门只是下限

护栏只保证你的策略**没作弊**。它不保证你的策略**有效**。

这两件事经常被混为一谈。一个策略在样本内跑出 25% 年化，可能只是因为参数挑得刚好适合那段历史。

所以我加了三种检验：

| 检验 | 回答什么问题 |
|---|---|
| `holdout` | 单次样本内/样本外切分，看成绩衰减多少 |
| `parameter_sweep` | 参数网格搜索 + 样本外验证，给出 **overfit gap** |
| `walk_forward` | 滚动前推，每段用历史选参数、在没见过的下一段上检验 |

`parameter_sweep` 里有两个数特别值得看：

- **`selected_oos`** —— 样本内最优参数，到了样本外还剩多少
- **`oracle_oos`** —— **直接用样本外最优参数**能拿多少

后者是搜索偏差的**上界**：它相当于"提前知道答案"能考多好。

两者之差 `overfit_gap` 越大，"样本内挑出来的最好"就越可能只是运气。

### 实测一个动量轮动

我拿一个最普通的动量轮动做例子（60 日动量选前 3 只，10% 债券），扫三个参数：

```bash
PYTHONPATH=src python3 -m vlab validate examples/momentum_rotation.py
```

结果：

```text
样本内最优 lookback=60  →  样本外夏普 0.341
先知基线   lookback=20  →  样本外夏普 0.518
overfit gap             =  0.177
```

读一下这三行：

- 样本内夏普最高的是 `lookback=60`（0.276）
- 到了样本外，它掉到 **0.341**
- 而样本内最差的那组（0.151），样本外反而拿到 **0.518**

**样本内最"好"的那组，样本外不如最差的那组。**

如果我只跑样本内，我会以为 `lookback=60` 是最优解，然后高高兴兴上线。

```text
全样本: 年化 6.40%  回撤 -52.05%  夏普 0.29  交易日 6686
窗口 A: 年化 7.52%  回撤 -26.54%  夏普 0.45  交易日 2039
窗口 B: 年化 8.71%  回撤 -42.10%  夏普 0.44  交易日 4779

=== 样本外检验（切分日 2019-03-06）===
样本内: 年化 6.52%  回撤 -52.05%  夏普 0.28
样本外: 年化 6.10%  回撤 -26.54%  夏普 0.34
年化衰减：-0.42 pp
```

```bash
git clone https://github.com/aazh2026/vlab && cd vlab

# 你的策略文件只需要定义一个函数
PYTHONPATH=src python3 -m vlab validate my_strategy.py
```

```python
def weights_fn(date, mat, dates, index):
    """返回 {资产代码: 权重}。只能用 date 及之前的数据。"""
```

几个刻意的设计：

- **零第三方运行时依赖**，纯 Python 标准库，`git clone` 就能跑
- **零 CDN**，面板是单个 HTML + 手写内联 SVG，断网也能打开
- **预热期可用**——`validate` 在完整历史上跑再切分指标，60 日动量这类需要回看的策略天然能用
- **77 个回归测试**，CI 覆盖 Python 3.9–3.12，每个历史缺陷都有一个具名用例钉死

## 老实说，它的局限

- **护栏挡住了显式的未来函数，挡不住"想当然的口径"**。窗口偏差这类问题只能靠人自觉分开陈述。
- **样本外不等于未来**。切一刀只能说明"这段历史之外它还行"，不能说明未来有效。
- **交易成本是简化的**——每次调仓一个固定费率，不按交易所实际费率表建模。
- **美股是全收益近似**，按固定年化分红率调整原始价格，不是精确的股息再投资。
- **walk-forward 是等权拼接**，每段起点归一为 1.0，衡量的是策略本身，不是一个连续账户的资金曲线。
- **网格搜索的样本外衰减本身就是过拟合的证据**——我扫过的那些参数，选出来的解基本没法用。

这个工具不承诺什么。它只做一件事：**让你的数字在被质疑的时候，站得住。**
