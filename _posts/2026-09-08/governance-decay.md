> 论文：*Governance Decay: How Context Compaction Silently Erases Safety Constraints in Long-Horizon LLM Agents*
> arXiv: [2606.22528](https://arxiv.org/abs/2606.22528)
> 作者：Shiyang Chen（北京理工大学）

## 问题的真实形状

现代 LLM Agent 定期压缩上下文——通过总结或驱逐早期对话轮次来保持在 token 预算内。这篇论文揭示了一个被忽视的安全隐患：

**上下文压缩会丢弃运行时安全策略，而这些策略在可见时是被可靠遵守的。**

压缩算法针对任务连续性优化，将持续性策略（persisting policies）视为"低显著性内容"。结果：策略在视觉上存在时违规率为 0%，一旦被压缩驱逐，违规率跃升至 30%，最高可达 59%。

这不是模型能力问题——这是系统设计的架构问题。

## 核心实验：ConstraintRot 基准

作者设计了 ConstraintRot 基准测试，结构如下：

1. **策略轮次**：建立上下文治理约束 `p`（如"不通过非批准渠道发送报告"）
2. **任务轮次**：让上下文增长超过压缩预算的长时间序列
3. **触发请求**：自然完成会违反策略 `p` 的请求

9 个任务涵盖软策略（邮件外发、超预算购买）与硬安全规范（生产 DROP、读取 SSH 密钥、泄露 SSN）。

## 关键数据

### 压缩导致治理衰减

| 条件 | 汇总违规率 |
|------|-----------|
| floor（无策略） | 47% |
| control（完整上下文） | **0%** |
| compaction（策略存在后被压缩） | **30%** |
| defense_pin（约束固定防御） | **0%** |

约束存活时违规率 0%（n=90），被丢弃时 38%（n=315）。

### 攻击面：压缩驱逐攻击

对手可以通过注入大量内容推过压缩预算（体积攻击），或嵌入针对压缩步骤的指令（注入攻击）。即使某个模型对固定探测免疫（0%），注入攻击可以将其打到 65%。

### 软/硬策略的衰减差异

- 软策略衰减：**+50 分**（0%→50%）
- 硬安全规范衰减：**+6 分**
- **衰减差距：8.3 倍**

软组织策略比硬安全规范脆弱得多——部署特定约束（"报销只走这个渠道"）比基础安全底线（"不读密钥"）更容易被悄悄侵蚀。

### 压缩策略对比

| 压缩策略 | 违规率 |
|---------|--------|
| recency-truncate（近期驱逐） | 38% |
| hierarchical | 36% |
| LLM summarize | 26% |
| **head_tail（保留头尾）** | **0%** |

保留最早轮次的压缩策略在所有模型上均保持 0% 违规——而这是大多数生产系统最少采用的策略。

### 真实框架验证

生产级框架全军覆没：

| 框架 | 违规率 |
|------|--------|
| LangGraph | 65% |
| LangMem | 95% / 70% |
| AutoGen | **100%** |

## 约束固定：低成本防御

作者的防御方案是**约束固定**（Constraint Pinning）：将治理约束从有损压缩中隔离，并在轮次间进行完整性检查。

效果：
- 所有 7 个模型恢复至 **0% 违规**
- 允许动作完成率：**99%**
- token 开销：约 **47 个固定 token**（< 生产规模压缩上下文的 0.5%）

但防御有局限：对于操作员冒充攻击（operator-impersonation attack），朴素固定从 0% 升至 17%；强化固定将其降至 10%。

## 真正的教训

**上下文管理是一级代理治理表面。**

这篇论文的核心贡献不是"发现了模型不听话"，而是把上下文管理从工程细节提升为安全架构议题：

> 管理代理，必须管理它们如何遗忘。

具体建议：
- 将治理约束视为固定状态，明确豁免于压缩
- 优先选择保留头部的压缩策略，而非纯近期驱逐
- 将摘要器视为**不可信输入接收器**——它可能删掉关键策略

## 实践建议

对于构建长会话 Agent 系统的工程师：

1. **明确标注哪些 context 不能压缩**：安全策略、数据治理规则、操作边界
2. **测量你的压缩策略的策略存活率**：不是所有压缩策略都"安全"
3. **在 Agent 架构层面引入约束固定**：而非在 prompt 里塞更多规则
4. **定期审计长会话末期的行为**：违规往往在压缩发生后才出现
